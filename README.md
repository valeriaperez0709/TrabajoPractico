# Trabajo Práctico – Estructuras de Datos

## Descripción del sistema
Este repositorio contiene el trabajo práctico. El proyecto está desarrollado en Java y busca aplicar algunos de los conceptos vistos en clase como el uso de clases, objetos y manejo de estructuras de datos.
El sistema incluye las clases necesarias para modelar el problema planteado en el trabajo y permite ejecutar las funcionalidades desde una clase principal.
